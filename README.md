# 🛒 FullCart — E-Commerce Platform

A modern and responsive **e-commerce web application** built with **React, TypeScript, Vite, Tailwind CSS, shadcn/ui, and Supabase**.

FullCart is designed to provide a clean and user-friendly shopping experience while demonstrating modern frontend architecture, reusable components, responsive UI development, and backend service integration.

## 🌐 Live Demo

**[View FullCart](https://fullcart-store-e-commerce.vercel.app/)**

## 🏗️ Architecture

The application follows a modern React-based architecture with reusable components and separated application concerns.

```text id="p0w4h7"
src/
├── components/       # Reusable UI components
├── pages/            # Application pages
├── hooks/            # Custom React hooks
├── lib/              # Utilities and shared logic
└── main.tsx          # Application entry point

supabase/
└── ...               # Supabase configuration and backend resources

public/
└── ...               # Static assets
```

> The project structure may evolve as the application grows.

## 💻 Getting Started

### Prerequisites

Make sure you have the following installed:

* **Node.js**
* **npm**

### 1. Clone the Repository

```bash id="b5xv6k"
git clone https://github.com/Sohrab-Malikzada/fullcart-store-E-commerce.git
```

### 2. Navigate to the Project

```bash id="j0v7m4"
cd fullcart-store-E-commerce
```

### 3. Install Dependencies

```bash id="7x3t0q"
npm install
```

### 4. Configure Environment Variables

If the application requires Supabase credentials, create a `.env` file and configure the required environment variables.

Example:

```env id="q1m6u8"
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

> Never commit real API keys, secrets, or private credentials to GitHub.

### 5. Start the Development Server

```bash id="x8d3p2"
npm run dev
```

Vite will provide the local development URL in the terminal.
